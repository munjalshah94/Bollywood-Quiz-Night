# Charades titles

Edit this file, then run `node sync_charades.js` to rebuild the `charades` block in `quiz.json`.
The script also checks every title against the answers in the other rounds and refuses to write if one overlaps.

- One title per bullet. Everything after ` — ` on a line is a note and is ignored.
- Only the Settings, Easy, Medium and Hard sections go into the game. Keep the spelling exactly as you want it shown on the cards.

- Points per title: 10
- Seconds per turn: 30
